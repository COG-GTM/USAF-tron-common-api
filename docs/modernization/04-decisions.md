# 04 — Program decisions required before modernization

Head commit inspected: `7b22ec561c2625ff1200156d058fcdd0ff022e69`. Evidence and confidence conventions: `00-inventory.md`. Risk IDs refer to `02-risk-register.md`; slice IDs to `03-slice-candidates.md`.

This table lists decisions that belong to the **program owner** — they set scope, acceptable behaviour change, and cut-over risk appetite. Decisions that are purely engineering (how to rewrite `SpecificationBuilder`, which OpenRewrite recipes to run, JUnit 4→5 migration mechanics) are listed separately in §2 and do **not** need program-owner sign-off.

## 2. Engineering decisions (no program sign-off needed, listed for completeness)

| Topic | Choice space | Recommendation |
|---|---|---|
| Jakarta migration mechanics | OpenRewrite recipes vs IDE refactor vs PR #4 diff replay | OpenRewrite dry-run first to size; replay PR #4 hunks only where recipes miss (R-02) |
| PowerMock removal | Mockito `mockStatic` (Mockito ≥3.4 inline) / refactor to injectable collaborators | `mockStatic` for the 3 affected test files; drop `mockito-inline`, `powermock-*`, and move `camel-test*`/`junit:junit` to test scope (R-07, R-15) |
| `WebSecurityConfigurerAdapter` replacement | `SecurityFilterChain` bean + `AuthenticationManager` bean for the pre-auth provider | Mirror the current chain order exactly (`WebSecurityConfig.java:43-62`) and keep `WebSecurityConfigDisabled` as a second `SecurityFilterChain` bean |
| Stacked `@PreAuthorize` merge | Merge SpEL with `and`/`or` vs meta-annotation composition | Merge per PR #4, but gated by the D-02 matrix tests |
| Hibernate dialect | `PostgreSQLDialect` auto-detect vs explicit | Remove explicit `PostgreSQL82Dialect` (`application.properties:7`), keep H2 `MODE=PostgreSQL` plus `NON_KEYWORDS` for the test profile |
| Actuator trace | Boot 3 `HttpExchangeRepository` replacing `HttpTraceRepository` | Rename only; keep persistence to `HttpLogEntry` |
| OpenAPI fixture | `springdoc-openapi-maven-plugin` vs test that hits `/api/api-docs` | Test-based (no new build plugin), stored under `src/test/resources` |
| JaCoCo / Checkstyle | Bump to versions supporting the target class-file level | JaCoCo ≥0.8.11 for Java 21, Checkstyle plugin 3.6.x (R-17) |
| Liquibase version | 4.2x LTS-style line vs 5.x | Smallest step that supports the target Boot's `liquibase-core` management, validated by D-05 evidence |
